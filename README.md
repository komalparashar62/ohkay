# Komal Parashar — Portfolio

Personal portfolio for Komal Parashar, a product designer with a product manager's perspective.

A single static page with no build step: `index.html` holds the markup, styles and scripts. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Works as-is on GitHub Pages, Vercel or Netlify: point the host at the repository root.

## Files

- `index.html` — the site
- `assets/komal-logo.svg` — the k. logo mark

## Enquiry form

The form prepares an email to ikomalparashar@gmail.com that the visitor copies or opens in their email app. To receive enquiries directly, connect the form to a form service such as Formspree or Netlify Forms.
